Welcome to the Terminal

Hello World! Welcome to my retro terminal-style blog. This is where I'll be sharing thoughts, code snippets, and various musings from the digital frontier.

Why Terminal Style?

There's something timeless about the green-on-black aesthetic of classic computer terminals. It's a tribute to the pioneers who built the foundations of modern computing.

How to Write Posts

Creating a new blog post is simple:

1. Create a new .html file in blog/posts/
2. Copy this template
3. Update the content
4. Add link to blog/index.html

That's it! No build process, no dependencies, just pure HTML and CSS.
